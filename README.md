# ⚙️ Minhas Configurações do VS Code

> Um repositório para centralizar e compartilhar minhas preferências e configurações pessoais do Visual Studio Code.

![Badge VS Code](https://img.shields.io/badge/IDE-Visual%20Studio%20Code-007ACC?logo=visual-studio-code&logoColor=white)
![Badge JSON](https://img.shields.io/badge/Config-JSON-orange?logo=json&logoColor=white)

## 🧐 Sobre

Este repositório contém o arquivo `settings.json` que utilizo no meu dia a dia. Ele define comportamentos do editor como:

- 🎨 **Tema e Aparência:** Cores, ícones e fontes.
- ✍️ **Formatação:** Regras de indentação, quebra de linha e salvamento automático.
- 🔌 **Extensões:** Configurações específicas para plugins instalados.

## 🚀 Como Usar

1.  **Clone o repositório:**
```bash
    git clone https://github.com/yVinicin/Config-VS-Code.git
```

2.  **Copie o `settings.json`** para a pasta de configurações do VS Code:
    - **Windows:** `%APPDATA%\Code\User\settings.json`
    - **Linux:** `~/.config/Code/User/settings.json`
    - **macOS:** `~/Library/Application Support/Code/User/settings.json`

3.  **Instale as extensões listadas acima** (via Marketplace ou pelo terminal):
```bash
    code --install-extension dracula-theme.theme-dracula
    code --install-extension miguelsolorio.min-theme
    # ...repita para as demais extensões
```
